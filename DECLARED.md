# Pre-event declaration

This boilerplate was prepared before the event. It includes development setup, a navy-themed placeholder card, and a backend health endpoint. No product features were built.

Libraries and development tools:

- React and React DOM
- Vite and @vitejs/plugin-react
- Tailwind CSS v4 and @tailwindcss/vite
- FastAPI
- Uvicorn

Transitive dependencies are installed by npm and pip. Frontend dependency versions are recorded in frontend/package-lock.json; backend dependency constraints are in backend/requirements.txt.
